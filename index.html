    Sync & cloud backup

    Keep your devices in sync and backed up in a secret gist on your own GitHub account.

    1. Create a GitHub token — a classic token with only the “gist” scope (the link pre-selects it; pick an expiration you’re comfortable with). A fine-grained token also works: Account permissions → Gists → Read and write.
    2. Paste it here and tap Connect. The token is stored only in this browser on this device — never in exports, backups or the gist.
